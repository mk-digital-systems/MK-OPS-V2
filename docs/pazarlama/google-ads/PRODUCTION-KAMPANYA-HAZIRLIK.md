# MK OPS — İlk Search Kampanyası Hazırlık Raporu

Bu belge Google Ads paneline manuel giriş içindir. Kampanya otomatik oluşturulmaz veya yayınlanmaz.

## Kampanya ayarları

| Ayar | Değer |
|---|---|
| Kampanya adı | MK OPS — Search — İlk Test |
| Kanal | Yalnızca Arama Ağı |
| Reklam grupları | Puantaj, Şantiye, Hakediş |
| Günlük ortalama bütçe | 200 TL |
| İlk test | 5 gün; nominal bütçe 1.000 TL |
| Konum | Türkiye; yalnızca hedef konumda bulunan veya düzenli bulunan kişiler |
| Dil | Türkçe |
| Arama iş ortakları | Kapalı |
| Görüntülü Reklam Ağı | Kapalı |
| Başlangıç eşleme türleri | Tam ve sıralı eşleme |
| Başlangıç teklifi | Tıklamaları en üst düzeye çıkar; TBM sınırı Anahtar Kelime Planlayıcı verisine göre belirlenir |
| Birincil dönüşüm | `ads_conversion_signup` — başarılı firma ve 48 saatlik deneme oluşturma |
| İkincil dönüşüm | `ads_conversion_whatsapp` — WhatsApp iletişim bağlantısı tıklaması |

Google Ads otomatik etiketleme açık olmalıdır. Beş günlük test için başlangıç ve bitiş tarihleri panelde açıkça ayarlanmalı; günlük bütçenin ortalama bütçe olduğu dikkate alınarak harcama her gün kontrol edilmelidir.

## İlk beş günlük kontrol

- Her gün arama terimleri raporunu inceleyip açıkça ilgisiz sorguları negatifleyin.
- `ads_conversion_signup` olayını teklif optimizasyonunda birincil, WhatsApp olayını gözlem amaçlı ikincil tutun.
- Etiket doğrulaması tamamlanmadan dönüşüm odaklı teklif stratejisine geçmeyin.
- Beş gün sonunda reklam grubu bazında tıklama, maliyet, kayıt ve arama terimi kalitesini karşılaştırın.
- Üründe bulunmayan GPS/konum takibi, bordro/SGK hesaplama, EKAP ve otomatik metraj çıkarma iddialarını eklemeyin.
